# pair-wise-yy-63 跨产品设计令牌治理与主题发布平台

维护基础令牌、语义令牌和组件别名，支持品牌主题、明暗模式与平台变体继承覆盖。包含令牌树、Monaco JSON 编辑、依赖图、循环引用与对比度校验、批量替换、变更评审、版本差异和发布锁定。

## 主题解析即发布事实

令牌上只保存**声明原值**（字面量或 `{token.id}` 引用，按主题声明）。`src/resolution.ts`
对每个主题独立做引用图 DFS 解析：

- 任一基础令牌改动，受影响主题的语义令牌与组件别名通过响应式解析结果**自动重算**，
  组件预览、依赖图、发布差异读取的都是解析值，不再有「改了基础色别名不变」或切主题看到上一版颜色的问题。
- 解析发现**循环引用**或**缺失引用**时，错误精确定位到卡住的那一枚令牌、所属主题与完整链路，
  发布按钮会停在发布准备页，门禁面板逐项说明（可点击定位令牌）。
- 对比度按四个主题的解析值逐一校验。

## 离线草稿与三方合并

- 侧边栏可切换在线/离线；离线期间的编辑按「令牌@主题」记账保存在 `localStorage`。
- 恢复在线后，草稿与远端清单基于上次同步基线做三方合并（`src/merge.ts`）：
  只改一边的直接合入；**两边同改同一字段时两边原值都保留**，在发布准备页选择采用哪一侧，
  未裁决冲突同样拦截发布。
- 同步/合并失败（网络或计算）不会丢弃这批编辑，状态标记为可重试，再次点击「同步合并」即可。
- 旧草稿（缺少 `themes` 字段或缺少明亮主题）加载时自动迁移：**升级成明亮主题**，原值写入
  明亮主题并作为其他主题的回退值。
- 发布差异按**各主题解析值**与上次发布快照逐主题生成；锁定发布时固化解析快照。

## 技术栈

Vue 3、TDesign、Pinia、Vue Router、TanStack Query、Axios、Monaco Editor、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62063`。令牌草稿、同步基线、待裁决冲突、发布快照保存在 `localStorage`。

```bash
npm run build      # 类型检查 + 构建
node scripts/bundle-smoke.mjs && node scripts/smoke.mjs   # 解析/合并/迁移逻辑冒烟测试
```
